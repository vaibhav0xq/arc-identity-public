# Contributing

Arc Identity is currently focused on wallet intelligence, Arc activity indexing, verified attestations, and reputation transparency.

Good contributions are small, reviewable, and evidence-driven.

Before opening a pull request:

- keep changes scoped to one problem
- avoid committing secrets, logs, generated files, or database exports
- run `npm run typecheck`
- run `npm run build`
- explain how the change affects reputation, wallet verification, or public API behavior

For scoring or trust logic changes, include the reasoning behind the model change and the edge cases tested.
