# Security Policy

Arc Identity handles wallet reputation data, public profile metadata, and transaction-backed verification flows. Please report security issues privately instead of opening a public issue.

## Reporting

Email: arcidentity.build@gmail.com

Please include:

- affected route, API, or workflow
- reproduction steps
- expected impact
- wallet addresses or transaction hashes only when needed for verification

Do not include private keys, seed phrases, production secrets, or sensitive user data in reports.

## Scope

In scope:

- wallet verification issues
- score or reputation integrity bugs
- public API data exposure
- authentication/session handling
- attestation verification bypasses

Out of scope:

- social engineering
- spam reports without technical evidence
- third-party provider downtime
- issues requiring compromised user wallets or leaked private keys
